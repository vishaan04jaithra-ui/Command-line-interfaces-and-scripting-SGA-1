 # Linux System Investigation

This task demonstrates Linux diagnostic commands used to inspect open files, file descriptors, error redirection, and system resource limits.

---

## Commands Used

### 1. Display Open Files

```bash
lsof -u $(whoami) | head -n 15
```

Displays a list of open files associated with the current user.

---

### 2. Examine File Descriptors

```bash
ls -la /proc/$$/fd
```

Displays the file descriptors used by the current shell process.

The standard descriptors are:

- **0** → Standard Input (stdin)
- **1** → Standard Output (stdout)
- **2** → Standard Error (stderr)

---

### 3. Redirect Error Output

```bash
ls /fake_directory > standard_out.txt 2> error_out.txt
```

Redirects standard output and standard error into separate files.

---

### 4. View Error File

```bash
cat error_out.txt
```

Displays the captured error generated by the invalid command.

---

### 5. Display Resource Limits

```bash
ulimit -a
```

Shows the current resource limits for the shell, including memory, processes, open files, CPU time, and stack size.

---

## Conclusion

The Linux investigation successfully demonstrated process inspection, file descriptor analysis, output redirection, and system resource monitoring using standard Linux commands.
